# CanchaYa

Propuesta académica de Práctica Profesionalizante II, UNaF, 2026.
Integrantes: Exequiel Matias Camacho y Miqueas Ezequiel Barrios.

CanchaYa propone una web para consultar y reservar turnos de canchas y gestionar la agenda de cada complejo deportivo.

Este repositorio registra el trabajo de documentación de la propuesta simulada. El historial fue preparado con asistencia de Codex. La aplicación, las pruebas funcionales y el despliegue se encuentran en etapa de propuesta.
